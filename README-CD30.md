# CD30瞳电游工作室展区特别版

这是专为CD30漫展展示定制的特殊版本，具有隐私保护、对话轮数限制等特性。

## 功能特性

### 1. 顶部横幅通知
- 显示"CD30瞳电游工作室展区特别版"标识
- 提供正式版文档链接
- 声明玩家二创属性

### 2. 默认AI模型
- 对话模型：akqrsc9j5u
- 绘图模型：nai-diffusion-4-5-full
- 默认开启分段输出

### 3. 对话轮数限制
- 每个会话最多30轮对话
- 实时显示剩余轮数
- 达到上限后提示开始新会话

### 4. 简化认证机制
- 无需Misskey账号登录
- 输入展区密码即可使用
- 认证状态持久化存储

### 5. 隐私保护机制
- 10分钟无操作自动清除对话
- 实时显示倒计时
- 保护前一位用户隐私

### 6. UI优化
- 适合公共展示的简洁界面
- 使用说明提示
- 隐私保护说明
- 重新开始对话按钮

## 快速启动

### Windows批处理
```batch
start-cd30.bat
```

### PowerShell
```powershell
.\start-cd30.ps1
```

### Linux / macOS
```bash
chmod +x start-cd30.sh   # 首次使用需添加可执行权限
./start-cd30.sh
```

### 手动配置
1. 复制 `.env.cd30` 为 `.env`
2. 修改环境变量配置
3. 运行 `python misskey_server.py`

## 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| CD30_ACCESS_PASSWORD | 展区访问密码 | cd30aliyaweb |
| CD30_REMOTE_API_KEY | 远程API密钥 | - |
| CD30_DEFAULT_MODEL | 默认对话模型 | akqrsc9j5u |
| CD30_DEFAULT_IMAGE_MODEL | 默认绘图模型（内部ID） | aob0wkxmi3 |
| ALIYA_HOST | 监听地址 | 0.0.0.0 |
| ALIYA_PORT | 监听端口 | 47653 |

## 展区部署建议

1. **网络配置**：确保展区设备可访问互联网
2. **密码管理**：定期更换展区访问密码
3. **设备准备**：准备备用设备防止故障
4. **人员培训**：工作人员熟悉重启操作

## 隐私保护说明

- 系统会在用户停止操作10分钟后自动清除对话记录
- 清除后自动开启新的空白会话
- 确保下一位观众不会看到之前的对话内容
